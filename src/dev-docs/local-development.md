Developers who are interested in installing Pressbooks locally for testing and development can do so with [Lando](https://lando.dev/download/) and [Bedrock](https://github.com/pressbooks/bedrock) using the instructions in this repo: https://github.com/pressbooks/local-dev-environment. All questions about the installation can be opened as issues in that repo. PRs and improvements always welcome!
